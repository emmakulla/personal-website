# Emma Kulla — Personal Website (DS4200)

A two-page personal website built with HTML, CSS, JavaScript, and D3.js.

## Files
- `index.html`: homepage and 200+ word introduction
- `interests.html`: second page, 200+ word description, list, image, and D3 chart
- `styles.css`: custom styling, responsive layout, fonts, and color scheme
- `chart.js`: interactive D3 horizontal bar chart
- `assets/`: original SVG illustrations

## Publish via GitHub Pages
1. Sign into GitHub, create a **public** repository (example: `personal-website`).
2. Click **Add file → Upload files** and upload the **contents of this folder**, not the `.zip` file. Ensure `index.html` is in the repository root.
3. Commit your files.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
5. Visit `https://YOUR-USERNAME.github.io/personal-website/` (replace the username and repository name).
6. Check the Home page, My Interests & Skills page, email link, and D3 chart. The chart needs an internet connection to load D3 from its CDN.
